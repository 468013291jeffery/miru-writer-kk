# kk 的 MIRU 私有交稿仓库

本仓库用于 kk 交稿和仓主审核。正式稿由仓主另行收录，不自动公开。

## 首次使用

接受 GitHub 邀请，用受邀账号打开本仓库，确认页首显示 Private。

## 网页交稿（无需安装 Git）

1. 在 Code 页面点击 Add file → Upload files，上传 Markdown、TXT 或 Word 文件；建议每章独立文件。
2. 每轮交稿使用新版本名，例如 ch01-20261108-v01.md，下一版用 v02，保留旧稿。Markdown 便于审阅差异。
3. 点击 Commit changes，填写修改说明，选择 Create a new branch，例如 submit/ch01-v01。
4. 提交后点击 Compare & pull request / Create pull request，目标分支选 main。
5. PR 标题写「交稿：第一章 v01」，描述修改和待确认问题，请 468013291jeffery 审核。
6. 收到意见后，在同一 PR 对应分支更新文件，不为同一轮修订重复开 PR。
7. 由仓主审核合并，再将通过的稿件收录到私有正式稿库。

## 防误改与恢复

不要直接改 main，不删除旧稿，不强制推送，不上传密码或 token。免费私有仓库无法强制分支保护；分支和 PR 是协作约定。独立仓库隔离不同编剧，正式稿由仓主单独管理。

误改时在文件 History 找到正确内容，以新的修复提交保存，不强制回退历史。
